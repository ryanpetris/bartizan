# Bundled Fonts

Unmodified upstream font files, licensed under SIL Open Font License 1.1. Copyright and license notices accompany each family.

- JetBrains Mono 2.304: https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304. Variable normal and italic TTF files from the release archive, with weights 100–800.
- Inter 4.1: https://github.com/rsms/inter/releases/tag/v4.1. Variable normal and italic WOFF2 files from the release archive, with weights 100–900.

The application loads these files locally using private CSS family names. It does not install fonts on the operating system or fetch fonts at runtime.
